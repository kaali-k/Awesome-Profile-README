## 📋 Step-by-Step Installation Guide

### Step 1: Create a Special Repository
To get a profile README, you must create a new repository with a name that **exactly matches your GitHub username** (e.g., if your username is `johndoe`, name the repo `johndoe`). 
- Make sure it is set to **Public**.
- Check the box to **Add a README file**.

### Step 2: Set up the Snake Animation (GitHub Actions)
For the snake animation to work, you need a GitHub Action that runs every day to generate the snake image.
1. In your new repository, click on **Actions** -> **New Workflow** -> **set up a workflow yourself**.
2. Name the file `.github/workflows/snake.yml`.
3. Paste [this exact code](https://github.com/Platane/snk/blob/master/README.md) into it and commit. (Search "snk github action" to get the standard action code). It will output to an `output` branch.

### Step 3: Copy the Template
Copy the Markdown code below and paste it into your `README.md` file.

### Step 4: Customize It!
- **CRITICAL:** Replace ALL instances of `kaali-k` with your own GitHub username!
- Change the `const kalana = { ... }` and `education = { ... }` code blocks with your own details.
- Update the Social Media links.
- Modify the Badges to match your Tech Stack.
